# Memory Game

Классическая игра «Найди пару» на чистом JavaScript (ES-модули) без фреймворков.

## Демо

https://satyricons.github.io/memory-game/

## Описание

Игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

**Возможности:**

- Поле 4×4 (16 карточек, 8 пар)
- Счётчики ходов и найденных пар
- Модальное окно победы с итоговым числом ходов
- Таблица лидеров (топ-10) с сохранением в `localStorage`
- Анимация переворота карточек

## Технологии

- HTML5
- CSS3 (Grid, 3D-трансформации)
- JavaScript (ES-модули)
- `localStorage` для хранения результатов
